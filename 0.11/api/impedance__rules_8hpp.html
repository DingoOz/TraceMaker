Detailed Description

Impedance and current rules on a real board (design doc 15 §5.3-5.4, P4): the board stackup gives, per routing layer, the line structure and the dielectric to the nearest reference layer; the closed forms of impedance.hpp turn a rule's target (z0_ohm / zdiff_ohm) into a width and gap.

Report-only: nothing here changes routing.

Assumption (dev/assumptions-m13.md, P4): the copper layer adjacent to a routing layer is its reference plane. Outer layers are microstrip over the next copper layer; inner layers are stripline between the copper layers above and below. A zone on the reference layer is reported as confirmation; without one the report says the plane is assumed. Boards without a stackup get nothing computed (doc 15 §3.6; CLAUDE.md rule 6).
