Detailed Description

TraceMaker's detailed router, version 1 (roadmap M4; design doc 05 §2, §5).

Octilinear A* on a fine lattice (optimal under its cost model), with legality decided lazily by exact clearance tests against the DRC's rule engine, then exact verification of every committed segment and via.
