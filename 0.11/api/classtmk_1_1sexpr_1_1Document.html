◆ append_child()

void tmk::sexpr::Document::append_child ( NodeId list,
std::string_view text )

Inserts text as new children at the end of list, each on its own line, indented one level deeper than the list's own line.

text must be one or more complete s-expressions without leading indent; embedded newlines are re-indented.
