Detailed Description

Renders the run report (doc 18 D3, D136) from a route summary (route --json, with the sections route --report adds).

The renderer reads nothing but the summary and does no arithmetic: every number and every name it prints is a field of the JSON, and the HTML marks each with its JSON pointer (data-src), so a reader can trace any figure.
