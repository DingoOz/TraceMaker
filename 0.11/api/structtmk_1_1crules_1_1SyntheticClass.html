Detailed Description

Net classes from rules (doc 15 §5.3-5.4 and §16, P5): impedance rules with a computed width/gap, and width rules with a current or a minimum width, become synthetic net classes for the nets bound to the rule's roles.

Only for instances at the apply threshold, only for nets the board leaves in its Default class (the board's own classes always win, §3.5), and only ever wider than the class the net has (never looser than a board rule). The router has one width per net: the outer-layer solution is used and detail says when inner layers would differ.
