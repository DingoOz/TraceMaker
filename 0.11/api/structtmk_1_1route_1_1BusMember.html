Detailed Description

A group as routed, measured on copper.

Length is what KiCad's skew check compares: track length (arcs included) plus the via length above, so a member with more vias than the others is longer by their height. KiCad also adds pad-to-die lengths and shortens a track end inside a pad or via; neither is modelled (micrometres, or zero).
