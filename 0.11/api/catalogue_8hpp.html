Detailed Description

Component-rule catalogue (design doc 15 §6.1): categories of components with their detectors, roles and layout rules.

The source is docs/component_rules.yaml; scripts/crules_catalogue.py converts it to src/crules/catalogue.json, which the build embeds (the engine has no YAML parser), and a ctest keeps the two identical.
