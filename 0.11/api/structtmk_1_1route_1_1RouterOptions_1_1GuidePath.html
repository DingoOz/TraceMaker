Detailed Description

Path guidance (doc 16 F1): a preferred path for a connection, found by matching its two pad centres.

Cells off the guide cost guide_pen pitches per lattice step in every search of that connection (a preference, never a block), so a guide that does not pass the exact checks only costs search effort. --guide FILE fills it from JSON (experiments); the breakout planner fills it itself.
