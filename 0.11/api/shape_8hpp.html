Detailed Description

Exact integer geometry for clearance checks (design doc 03 §1).

Every copper shape is a "rounded core": a point, an open polyline or a closed polygon, inflated by a radius r. Tracks are 2-point polylines with r = width/2, round pads are points, ovals are segments, round-rect pads are rectangles shrunk by the corner radius and inflated back. Gap tests compare squared distances in 128-bit integers, so "closer than" decisions are exact.
