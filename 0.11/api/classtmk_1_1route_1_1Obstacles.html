Legality of a probe shape.

Result: 0 = free, 1 = only conflicts with rippable routed copper (owners are appended to owners when given), 2 = blocked by fixed copper, holes, edges or keepouts. With ignore_routed = false, routed copper counts as blocking (result 0 or 2 only).

◆ positional_rules()

bool tmk::route::Obstacles::positional_rules ( ) const
inline

Custom disallow rules that depend on position, size or footprint (doc 05 §34), for new copper of net: a track whose copper is s with width on layer, or a via of diameter d spanning [l0, l1].

The state checks above include them (blocked, 2); a disk's rules are judged on its copper, without the margin.

◆ kFree

std::int32_t tmk::route::Obstacles::kFree = -1
staticconstexpr

Fixed-obstacle code of a disk (fixed copper, fixed holes, edges, keepouts, outline), independent of the probe's own net: kFree, kBlocked, or the single net id whose own copper is the only conflict (so the disk is legal for that net only).

Clearances use probe_net's class; diff-pair relief is not applied (safe).
