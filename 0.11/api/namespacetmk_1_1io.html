SrjExport tmk::io::srj_export ( const std::string & problem_text,
const model::Board & routed )

Writes the tracks and vias of routed (a board made by srj_to_kicad from problem_text, then routed) as SRJ traces: one trace per pair of consecutive points of a connection, following the copper between their pads, then the copper no such path used.

Nets are matched by name, pads by position.

The board is the problem mirrored in y at the same coordinates (x, -y), one footprint per componentId.

The output depends only on the problem and the options (UUIDs are counted, not drawn), so it is byte-identical across runs.
