 The board model (design doc 02 §3): every object TraceMaker reads from a .kicad_pcb, in absolute integer-nanometre coordinates, with a link back to its s-expression node for lossless writing.

 Schematic connectivity as exported by KiCad (kicad-cli sch export netlist –format kicadsexpr).

 Design rules as KiCad defines them (design doc 08 §3–4): board minimums and net classes from the .kicad_pro project file, plus custom rules from the .kicad_dru file.

 The board's physical stackup as KiCad stores it in (setup (stackup ...)) (design doc 15 §5.3): read-only, used to turn impedance rules into widths and gaps.
