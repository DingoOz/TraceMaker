Detailed Description

The placement pipeline (design doc 04 §3): full runs A (quadratic B2B) → B (SimPL spreading) → C (rotations) → D (legalisation) → E (annealing); refine starts from the current placement and runs D (only for illegal parts) → E.

Both report the exact lower bounds of doc 04 §1 (L4) and what was achieved.
