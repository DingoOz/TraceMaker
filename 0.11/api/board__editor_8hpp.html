Detailed Description

Edits a loaded .kicad_pcb document in place, KiCad style (design doc 08 §3).

Only the nodes TraceMaker owns change: new segment/via nodes, removed tracks, and footprint placement. Everything else is kept byte for byte. Re-read the document after editing to get an updated board model.
