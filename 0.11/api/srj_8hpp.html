Detailed Description

Simple Route JSON (SRJ), tscircuit's autorouting problem format (design doc 08 §9, D90): read a problem, write it as a self-contained KiCad board plus project, and write a routed board's copper back as SRJ traces.

Field reference: lib/types/srj-types.ts in github.com/tscircuit/tscircuit-autorouter (MIT) and the page "advanced/simple-route-json" on docs.tscircuit.com. SRJ is millimetres, y up, with layers named "top", "inner1" .. "innerN", "bottom"; KiCad is y down, so y is negated on the way in and back on the way out.
