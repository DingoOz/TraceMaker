Detailed Description

The two ways to talk to a Session (design doc 19 §6).

Both call Session::call, so they cannot differ.

MCP over standard input and output: JSON-RPC 2.0, one message per line, initialize, tools/list, tools/call, ping, and the notifications/initialized notification. Any MCP client can be the agent. Standard output carries protocol messages only. JSON lines: one request {"tool": NAME, "args": {...}} per line, one response per line (the tool's result, or {"error": ...}).
