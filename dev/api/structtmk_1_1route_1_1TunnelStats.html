Detailed Description

Package tunnels (doc 05 §52): a connection between two perimeter pins of one dense package on the same net (the core rail's three pins, the supply pins of a package) goes where the designer puts it: a short stub and a via straight out of each pin, and the run between the two vias on the other layer, under the package.

The run is one search (A*, octilinear, exact checks) between the two via sites; nothing is placed unless the whole tunnel passes.
