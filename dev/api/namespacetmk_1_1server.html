◆ default_host()

std::string tmk::server::default_host ( )

Who can reach the viewer (issue #4, docs/09-visualization.md "Security", D116): by default only this machine.

A viewer bound to any other address requires a token on the page and on /ws (a random one unless token is given; allow_open serves without, a deliberate choice that is said so), and every WebSocket upgrade must come from the server's own origin, so a web page open in the user's browser cannot read the stream. The bind address when none is given: $TM_VIEW_HOST if set, else 127.0.0.1 (this machine only).
