◆ via_clearance_extra

Coord tmk::model::DesignRules::via_clearance_extra = 0

Router only, never read from a file: added to every clearance between a via and other copper.

The relaxed stages of a clearance ramp lower all clearances; with this set back to the difference, vias keep the board's own clearance while tracks route thin (doc 05 §67: a thin sketch's tracks thicken, its vias parked in cells too small for them do not).

Definition at line 124 of file rules.hpp.

◆ via_fixed_clearance_extra

Coord tmk::model::DesignRules::via_fixed_clearance_extra = 0

Router only: added to the clearance between a new via and fixed copper (the board's pads, holes' copper, tracks, vias, zones), not routed copper.

A relaxed stage's vias then keep the board's clearance to what legalising cannot move (doc 20 §2.6).
