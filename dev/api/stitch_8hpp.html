Detailed Description

Stitching vias (doc 05 §39.3): after routing, vias of a plane's net are added where fills of that net lie over each other on two or more layers (plane stitching), and next to the vias of signals that need a reference plane (return-path stitching).

Every via passes the router's exact check against the refilled zones, and is kept only if a second refill still joins it to its net's fill on two layers.
