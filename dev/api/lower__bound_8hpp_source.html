3// Exact lower bound on weighted HPWL (design doc 04 §1 level L4).
4//
5// Without overlap and outline constraints, minimising Σ_n w_n (max_i x_i − min_i x_i) over the movable
6// parts' positions is a linear program whose constraints are all differences (U_n − X_p ≥ o, X_p − L_n ≥ −o),
7// so its dual is an uncapacitated min-cost flow from the nets' upper nodes U_n through the parts (or the fixed
8// "ground" node) to the nets' lower nodes L_n. Solved exactly in integers by successive shortest paths
9// (Ahuja, Magnanti, Orlin, "Network Flows", 1993, ch. 9). By LP duality the optimum equals the minimum of the
10// relaxed placement problem, so it bounds every legal placement from below.
