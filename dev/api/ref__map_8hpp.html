Detailed Description

Where a track is over a void of its reference plane (issue #24, docs/05-routing.md §44, D117).

A fast signal wants solid copper under it on the adjacent layer: where the plane has a split, a slot, a cut-out or an antipad field the return current has to go round (docs/05 §42 measures the detour after the route). Here the same question is asked before the route, for every cell of the router's lattice: on each copper layer that has a plane next to it (an adjacent layer whose zone fills cover a good part of the board), is the cell's centre over the plane's copper? The router charges critical nets for the cells where it is not.

The map is a cost, not a rule: the exact check of every commit is unchanged. Vias a route adds make antipads the fills in the file do not have yet; the audit after the route (analysis/return_path.hpp, on a refilled board) sees those.
