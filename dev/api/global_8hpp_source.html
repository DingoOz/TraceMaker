3// Global placement (design doc 04 §3 A–C).
4//
5// (A) Quadratic placement with the bound-to-bound (B2B) net model: Spindler, Schlichtmann, Johannes,
6// "Kraftwerk2 — A Fast Force-Directed Quadratic Placement Approach Using an Accurate Net Model",
7// IEEE TCAD 27(8), 2008. Each net connects every pin to the net's two extreme pins with weight
8// w·2/((p−1)·|x_i − x_j|), which reproduces HPWL at the linearisation point; the SPD systems are solved
9// with Jacobi-preconditioned conjugate gradient (Eigen) and re-linearised.
10// (B) Spreading: SimPL (Kim, Lee, Markov, "SimPL: An Effective Placement Algorithm", ICCAD 2010 / TCAD
11// 2012): alternate the quadratic solve (lower-bound placement) with a rough legalisation (upper-bound
12// placement) and pull the parts towards it with anchor pseudo-nets of growing weight.
13// (C) Rotation: coordinate descent; each step is the exact HPWL optimum for one part with the others fixed.
