Detailed Description

Repair windows (issue #56, doc 05 §75, D172): finish a nearly routed board without routing all of it again.

A plain run keeps every track and via of the input as fixed copper, so a pin that the neighbours' fan-outs wall in stays open ("fixed copper encloses the pin"). The repair lifts the unlocked copper near each open connection (whole pieces: the tracks and vias of one net between its pads), routes the board again with what is left fixed and the open connection first, and keeps the result only if no pads that were joined come apart and fewer connections are open (rule 4). On failure the window grows. Ripping is limited to the window: everything outside stays as it was.
