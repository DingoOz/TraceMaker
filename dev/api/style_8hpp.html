Detailed Description

Style metric (doc 05 §39.2): how tidy a set of tracks is, per connection and per board.

It only measures; no pass optimises it. Everything is counted in integers (nm, cross and dot products), so the numbers are the same on every machine and at every thread count.

The patterns follow what layout reviewers flag by eye; tscircuit's pcb-trace-linter (segments off the 45 degree directions) and check-ugly-traces (removable jogs) were read for which patterns to count. No code of theirs is used.
