3// Reference-return audit of high-speed nets (issue #7, docs/05-routing.md §42, D114).
4//
5// KiCad's DRC cannot tell whether a fast trace has continuous copper under it. A dogbone escape punches antipads through the reference
6// pour, a plane can be split, a layer change can come without a nearby stitch: the signal is DRC-clean and its return current still
7// walks around the void, which grows the loop area and the inductance. This pass answers a geometric question per net: does the trace
8// have copper under it on the adjacent reference layer, and where it does not, how far does the return detour?
9//
10// It is read-only (it adds nothing to the board) and it is a geometric model, not a field solver: the return of a signal over copper
11// is taken to be its mirror image on the reference layer, across a void it is the shortest path that stays on the remaining reference
12// copper (Dijkstra over the visibility graph of the reference polygon's vertices; Lee and Preparata 1984), and at a layer change it
13// closes through the nearest stitching via of the reference net, or the nearest capacitor between the two reference nets, within a
14// radius. The return does not close through "one assumed GND ball": at a footprint the nearest pad of the reference net is the
15// assumed return pad (the comment on the issue).

28struct ReturnPathOptions {

34 // "PATTERN=LAYER": the reference layer of the nets that match, instead of the adjacent layer with the most copper under the trace.
35 std::vector<std::pair<std::string, std::string>> reference_layers;
36 double stitch_radius_mm = 5.0; // how far a stitching via or a capacitor may be from a layer change
37 double sample_mm = 0.05; // spacing of the samples along a trace
38 double min_void_mm = 0.1; // a stretch without copper shorter than this is a sampling artefact, not a void
39 double warn_detour_mm = 2.0; // thresholds: warnings, not DRC errors
40 double warn_separation_mm = 1.0;
41 bool refill = true; // zones without fills are refilled first (the engine's refill, not KiCad's)
42 bool refill_always = false; // refill every zone: the fills in the file predate copper that was just routed

45struct ReturnVoid {

47 geom::Point entry, exit; // where the trace leaves and regains copper under it
48 double signal_mm = 0; // the trace between them
49 double return_mm = 0; // the return path between them (the shortest path on the reference copper)
50 double detour_mm = 0; // return - signal, at least 0
