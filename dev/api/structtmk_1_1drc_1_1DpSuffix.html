Detailed Description

compiled custom-rule condition

A differential-pair net name as KiCad 10.0.6 reads it (DRC_ENGINE::MatchDpSuffix): from the end, digits and underscores are skipped, then P or + makes the positive half and N or - the negative one. complement is the other half's name and base the name before the polarity character, so D_P1 pairs with D_N1 on base "D_". Polarity 0: not a pair name.
