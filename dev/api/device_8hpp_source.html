3// GPU discovery and memory admission control (design doc 07 §4).
4//
5// The GPUs on the development machine are shared with other jobs, so free memory is scarce and changes
6// over time. Callers ask `has_free_memory` before large allocations and fall back to the CPU reference
7// path when it fails; results are identical either way.

18struct DeviceInfo {
19 int index = -1; // backend runtime index; select by uuid/name for stability
20 std::string name;

22 int cc_major = 0, cc_minor = 0;

36// True when `bytes` plus a safety margin fit in the device's free memory right now.
