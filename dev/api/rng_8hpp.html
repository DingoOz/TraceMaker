Detailed Description

Deterministic, counter-based random numbers (design doc 02 §6.2).

Every random decision is a pure function of (job seed, stage, item, counter), so results never depend on thread timing, and CPU reference code and CUDA kernels produce identical streams.

Philox4x32-10: Salmon, Moraes, Dror, Shaw, "Parallel random numbers: as easy as 1, 2, 3", SC 2011. SplitMix64: Steele, Lea, Flood, "Fast splittable pseudorandom number generators", OOPSLA 2014.
