Detailed Description

The run report (doc 18 D3, D136): the sections of the route summary that a designer needs to audit a run and that the plain summary does not carry: which rules were read and which were not, and the DRC of the board before and after the route.

The report file itself is rendered from the summary alone (report/render.hpp), so every number in it is a field of the JSON.
