Detailed Description

Buses (design doc 05 §38): groups of nets that belong together (a data bus, an address bus, a parallel display interface).

This file holds what does not need the router: how a group is named on the command line, how groups are found in the net names, which skew limit the board's rules give a group, and the measurement of a routed group. The routing of a group lives in the router (route/router.cpp, "buses").
