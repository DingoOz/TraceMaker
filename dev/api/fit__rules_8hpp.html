Detailed Description

Rule fit (route –fit-rules, doc 20 §2.8, D194): relax the rules a board's own copper already breaks, to what that copper has.

A board whose pads or existing tracks break a rule cannot be routed under that rule the way it was laid out. The designer-oracle test (bench/records/oracle-2026-11) found this on boards that never complete: card-edge connector pads inside the copper-to-edge clearance, tracks closer to holes than the hole clearance, tracks narrower than the minimum width. All PCBench boards are in the KiCad 5 format, which stores no edge or hole clearance, so KiCad 10's defaults (0.5 mm and 0.25 mm) hold for boards designed without them.

The fit runs the DRC on a reference board (the input, or an earlier layout of it), takes for every fitted rule the smallest value its violations measure (for the clearance, their low decile), and lowers the rule to that value, never below a floor. With tracks on the reference it also lowers each net class's track width and via size to what the reference's tracks of that class use. It only ever relaxes, and every change is reported. The output then breaks the board's stated rules where the fit relaxed them: KiCad's DRC reports those, as it does for the reference.
