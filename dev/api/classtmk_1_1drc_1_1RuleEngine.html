◆ router_hole_clearance()

Coord tmk::drc::RuleEngine::router_hole_clearance ( ) const
inline

Hole-to-copper clearance the router keeps between a hole and other nets' copper: the board minimum raised to every applied custom hole_clearance rule.

The router's checks and caches have no per-pair hole rule, so a rule with a condition or a layer is kept everywhere (conservative, rule 6; a warning says so). The DRC stays exact (hole_clearance above).

void tmk::drc::RuleEngine::use_zone_clearance_overrides ( )

KiCad applies a copper zone's own clearance to its fill (ZONE::GetLocalClearance): the larger of it and the net-class clearance, unless a pad override or custom rule decides.

The DRC enables it; the router does not yet (D51: changing it needs a routing benchmark run).
