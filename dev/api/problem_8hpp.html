Detailed Description

Placement problem extracted from a board (design doc 04 §2): parts with courtyards, holes and pins per rotation, weighted nets, the board outline, keepouts and spacing rules.

Everything is in integer nm; a part's geometry is stored as offsets from its footprint origin for each of the four 90° rotations.
