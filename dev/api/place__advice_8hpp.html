Detailed Description

Placement advice (design doc 17 §9 stage 4, issue #26): proposed placements and moves for tracemaker-place, written by a person, a script or a language model.

The placer never talks to a model; the file is one more input, read strictly.

{ "version": 1, "note": "free text, logged and never acted on", "seeds": [{"name": "U3 to the west", // a whole proposal: these parts moved together "moves": [{"ref": "U3", "at": [42.5, 18.0], "rotate": 90}]}], "eco": [{"ref": "C12", "at": [40.0, 21.5]}] // single-part moves, tried first among the ECO moves }

"at" is the footprint origin in millimetres on the board file's axes; "rotate" is the footprint's absolute orientation in degrees as KiCad shows it (default: unchanged) and must be the part's own orientation plus a multiple of 90 (the placer's rotation states). A seed becomes a candidate of the routability loop and an "eco" move a candidate of the ECO step: each is routed with the same budget as the placer's own candidates and kept only when it leaves fewer connections unrouted (CLAUDE.md rule 4). A proposal that adds an overlap or puts a part outside the board is skipped with a note; one that names a locked or otherwise fixed part, an unknown reference, an unknown key or an orientation the part cannot take is refused with an error naming the entry (rule 6: locked parts never move; a typo must not silently drop a proposal).
