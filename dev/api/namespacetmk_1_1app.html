A group measured on the copper of b (joined: route::nets_joined of the same board), as the JSON object of the route summary's buses array and of tracemaker buses --json; line, if given, gets the one-line text form.

Lengths are KiCad's: tracks plus the stackup height of the vias (rules says whether the project counts it).

bool detect,
double skew_mm,
std::vector< std::string > * notes = nullptr )

Buses (doc 05 §38): the groups specs ("NAME=PATTERN") name on the board, then, with detect, the groups found in the net names that share no net with an earlier group.

Each group gets the skew limit of the board's custom rules, else, for groups from specs, skew_mm (0 = none). notes receives warnings. Throws on a bad spec.
