Detailed Description

Octilinear clean-up (doc 05 §80, D187, M23 E3): a new track that runs off the eight directions (0, 45, 90, ... degrees) is replaced by a dogleg of two tracks that are on them, through one of the two points that split it into a diagonal and a straight leg.

A dogleg is kept only if both legs are free in the router's exact check, against everything including the copper already changed, and if neither end makes an acute corner with the copper it joins. Ends do not move, so connectivity is unchanged.
