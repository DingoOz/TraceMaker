Detailed Description

Router-in-the-loop placement (design doc 04 §3 G) and ECO placement (doc 04 §4).

Both take the router as a callback (RouteFn), so this library does not depend on tm::route and the logic can be tested with a synthetic router. The caller routes with a deterministic work budget, so every decision here is reproducible. A placement is only ever accepted when it routes more connections than the incumbent (transactions, CLAUDE.md rule 4); locked and otherwise fixed parts never move (rule 6).
