Detailed Description

Lossless s-expression documents for KiCad files (design doc 08 §3).

The parser keeps the original text and records each node's byte span, so writing an unmodified document reproduces the input byte for byte. Edits are recorded as span replacements and insertions and applied on write; untouched text is never re-formatted.
