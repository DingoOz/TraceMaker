Detailed Description

What a pair is routed at.

Sources, highest first: a custom rule's diff_pair_gap (opt, else min) and diff_pair_uncoupled (max); the net class's diff-pair width/gap/via gap when the project sets them; else the net class width and the clearance between the two halves (the tightest legal coupling). Never below the board minimums or the clearance KiCad requires between the halves (the class diff-pair gap relaxes it only for pairs KiCad recognises by name, inDiffPair).
