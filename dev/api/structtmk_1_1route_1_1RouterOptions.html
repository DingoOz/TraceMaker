◆ critical

std::vector<std::pair<std::string, int> > tmk::route::RouterOptions::critical

Critical nets (issue #24, doc 05 §44; route_job fills these from –critical-nets and the component rules' roles).

critical is net name and tier (1 = most critical). With critical_first they are routed before all other nets, tier by tier (after first_nets), also after restarts. A via costs them critical_via_mult times as much (>= 1). A track of theirs over a void of the adjacent reference plane (route/ref_map.hpp) costs split_cost pitches more per lattice step; split_hard closes those cells to them instead. All off by default: a run without these options is the run it was.
