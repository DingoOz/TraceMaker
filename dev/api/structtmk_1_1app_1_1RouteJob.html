◆ advice

std::string tmk::app::RouteJob::advice

Advice (doc 17, issue #26).

The engine never talks to a model: it reads an advice file, and an advisor (any program that turns a stuck report into an advice file) is consulted only when the deterministic route leaves connections open. –advice FILE: typed hints (src/advice/advice.hpp); advised variants run next to the unadvised ones

◆ widen_power

bool tmk::app::RouteJob::widen_power = false

After-route passes (doc 05 §39), all off by default.

Each changes the new copper only through the router's exact check and is kept only if no net has more unconnected items with it than without (rule 4). –widen-power: new tracks narrower than their net class width go back up to it where there is room; nets with a target (–widen-net "PATTERN=WIDTH_MM", or a width the component rules computed) are widened towards it.
