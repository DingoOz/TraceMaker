Detailed Description

Builders for viewer protocol v1 messages (docs/13-viewer-protocol.md).

Pure functions returning one JSON object per message, ready for events::Sink::publish(). No Boost or networking: the router links only this library (tm::viz) and publishes into whatever Sink it was given.

Every message starts with its "type" key (insertion-ordered JSON), so a server can classify messages by looking at the first bytes without parsing them.
