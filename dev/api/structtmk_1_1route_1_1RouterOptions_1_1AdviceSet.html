Detailed Description

Hints from an advice file (src/advice, doc 17).

They are not applied to the variants the portfolio would run anyway: route_portfolio adds variants extra variants that carry them (the next ones of its list, the variants a plain run with that many more would have added), so the winner of the total order can only be better than without advice, never worse (rule 4).
