3// Persistent knowledge base (design doc 06 §4, failure-memory tier T3): what was learned on earlier runs.
4//
5// * per board-feature bucket: how often each router variant was run and how often it produced the best result
6// (Thompson-sampling bandit over portfolio variants);
7// * per board (content hash): connections that failed before, so a re-run routes them first.
8//
9// SQLite file, default ~/.local/share/tracemaker/kb.sqlite. Every call is best-effort: a missing or locked
10// database never stops routing.
