Detailed Description

Live status of this process for the progress site's live page (devsite /live, D165): what the process is doing, written as JSON to <dir>/<pid>.json about once a second by a background thread (written to a temporary file and renamed, so a reader never sees half a file).

<dir> is $TM_LIVE_DIR, else $XDG_CACHE_HOME/tracemaker/live, else ~/.cache/tracemaker/live. On by default; TM_LIVE=0 turns it off. A process that ends within its first second writes nothing.

Write-only: the engine never reads any of it back, so it cannot change a result (rule 2). The router updates its slot with relaxed atomic stores, which cost next to nothing next to a search; everything else takes a mutex a few times a second.
