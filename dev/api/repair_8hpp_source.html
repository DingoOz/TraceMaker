3// Repair windows (issue #56, doc 05 §75, D172): finish a nearly routed board without routing all of it again.
4//
5// A plain run keeps every track and via of the input as fixed copper, so a pin that the neighbours' fan-outs wall in
6// stays open ("fixed copper encloses the pin"). The repair lifts the unlocked copper near each open connection (whole
7// pieces: the tracks and vias of one net between its pads), routes the board again with what is left fixed and the
8// open connection first, and keeps the result only if no pads that were joined come apart and fewer connections are
9// open (rule 4). On failure the window grows. Ripping is limited to the window: everything outside stays as it was.

22struct RepairOptions {
23 std::vector<double> radii_mm{1, 2, 4}; // window radii around each end of an open connection, tried in turn
24 long step_work = 3'000'000; // work budget of each routing attempt (search expansions, rule 5)
25 int max_branches = 64; // a window that would lift more branches ends the growth for that connection
26 int max_conns = 64; // open connections tried at most (the first ones of the router's list)
27 double time_limit_s = 0; // > 0: no attempt starts after this many seconds (safety only; work decides)
28 std::vector<model::NetId> keep_nets; // nets whose copper is never lifted (coupled pairs, bus members)
29 // Where the copper to lift is looked for (doc 20 §2.11, D195). "ends": round the two ends of the open connection (the radii above).
30 // "route": along the route the connection takes with every other net's unlocked copper off the board (one more routing run per
31 // connection; a connection with no such route is left alone), on the layers that route uses. "both": along the route, then the ends.
32 std::string select = "ends";
33 std::vector<double> route_radii_mm{0.2, 1}; // "route": distance from that route's copper, tried in turn
34 // An attempt routes only the open connection's net and the nets it lifted copper of; every other net is left as it is (its open
35 // connections too). Without it each attempt routes everything that is open, and on a board with many open connections the attempt's
36 // budget goes to those: PCBench d20 with two layers added, 129 open, 126 attempts, every one ended with more open than before.
37 bool focus = false;
38 // > 1: every attempt runs this many portfolio variants (different orders and costs) on `threads` threads and takes the best; each has
39 // `step_work`. 1 = one router with the job's options, as before.
40 int variants = 1, threads = 0;
41};

43// One routing attempt: an open connection, a window radius, what it lifted, and whether it was kept.
44struct RepairStep {
45 std::string conn; // "NET A-B"
46 bool along_route = false; // the window follows the connection's route on the bare board, not its ends
47 double radius_mm = 0;
48 int pieces = 0, tracks = 0, vias = 0; // copper lifted (pieces: branches)
49 int open_before = 0, open_after = 0; // open connections of the board (pads not joined), before and after the attempt
50 bool split = false; // some pads that were joined came apart
51 bool kept = false;
52 long work = 0;
53};

81// Copper that joins no pad after a run and is the run's doing (doc 20 §2.14, D198). Lifting part of a route can leave a piece of
82// it standing: a via and two short tracks, or a run on an inner layer whose vias went. The router counts pads, so such a board is
83// complete for it, but KiCad counts every piece of copper of a net and reports the piece as unconnected.
84// `now` is the input as it is after the run (lifted copper gone), `new_tracks` and `new_vias` the run's copper, `before` the input as
85// read. A group of touching tracks and vias with no pad, zone, graphic, arc, locked item or free via in it is cut when it holds new
86// copper, or when one of its items was joined to a pad in `before`. A group that joined no pad in the input either is the user's
87// and stays. Links are KiCad's (copper of one net that overlaps is joined), so nothing KiCad sees as connected is cut.
88struct IslandCut {
89 std::vector<int> base_tracks, base_vias; // indices into now.tracks / now.vias, ascending
90 std::vector<char> new_track_cut, new_via_cut; // per new track / via: 1 = cut
91 int islands = 0;
92 bool any() const { return islands > 0; }
93};
