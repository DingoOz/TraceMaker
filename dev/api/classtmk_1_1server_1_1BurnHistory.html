Detailed Description

The burndown of the open connections, kept for viewers that connect during a run (stats_history, doc 13): one point per stats message and the time each stage began.

A stats message whose time goes backwards, or whose total changes, starts a new run. Long runs keep at most kMax points by dropping every other one, so the history stays a few tens of kilobytes.
