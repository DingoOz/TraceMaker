# Tutorials

Lessons that take you from nothing to a routed board, one step at a time. The commands of the first tutorial were
run before they were written down, and the output shown is what they printed (release 0.10.0, 2026-10-21). The
plugin tutorial follows the steps that `scripts/kicad_gui_roundtrip.py` checks in KiCad 10.0.6.

- [Route your first board](first-board.md): build TraceMaker, route the example four-layer board, check it.
- [Route from inside KiCad](kicad-plugin.md): install the plugin, route the open board with one click, undo it.
