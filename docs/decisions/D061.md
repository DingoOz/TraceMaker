# D61 — JSON protocol kept, FlatBuffers dropped

## Decision

The viewer protocol and replay log stay JSON; the FlatBuffers schema is dropped from the roadmap

## Alternatives

A `.fbs` schema with C++ and JavaScript codecs

## Reason

D45's reasons held: zstd JSON logs are 12–13× smaller than plain, recording does not change routing, the browser parses JSON natively. No measurement shows the protocol as a bottleneck
