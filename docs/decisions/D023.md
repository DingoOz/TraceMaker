# D23 — Exact windows by own branch and bound, not CP-SAT

## Decision

Exact windows (doc 04 §3 F) by own branch and bound over candidate slots (own spot, other window parts' spots, HPWL-median spot; 4 rotations), not CP-SAT

## Alternatives

OR-Tools CP-SAT

## Reason

OR-Tools is not installed; B&B is exact over its candidate set, has a full-enumeration reference path, and is small enough to run inside annealing
