# D54 — Connection planning by copper gap, group re-route removed

## Decision

Connection planning weighs pad pairs by the gap between their copper, not by centre distance (`--plan-gap`, default on; doc 05 §17). The group re-route (R4 trial) is removed

## Alternatives

Keep centre distance; keep the group re-route as an option

## Reason

Fixed budget, one variant, 24 boards: 11,905 → 11,986 routed. KiCad-judged tiers A–D neutral (tier D side by side 16,618 → 16,622, clean pass equal), no added errors. The group re-route changed no board's result
