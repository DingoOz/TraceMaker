# D15 — New placement kept only if it routes as well

## Decision

Placement keeps a new placement only if it routes at least as well as the input under the same router budget (`--route-check`, `--mode auto`)

## Alternatives

Trust HPWL

## Reason

Lower HPWL from denser packing routed worse on PCBench (13 vs 15 fully routed boards)
