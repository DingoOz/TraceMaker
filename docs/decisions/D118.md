# D118 — Milestones M17 to M21 follow the owner's answers

## Decision

The next milestones (M17–M21, docs/11, doc 18) follow the owner's answers of 2026-10-15: hobbyists first with high speed limited to the Kookabus boards; KiCad 11 is supported; pin swap is a **proposal file only** and never written into a board; the agent interface is built with a pre-agreed stop rule (it must route more than the plain run at the same compute on a held-out half, otherwise it stays a library). Order: install and measure, session server and agent interface, KiCad 11, hobbyist wins, Kookabus high speed

## Alternatives

Signal-integrity features first (the issues #4–#24 line of work); a pin-swap pass that edits nets; building the agent interface without a stop rule; waiting for KiCad 11 before preparing

## Reason

The audience decides what is valuable: a release nobody can install, or a layer count that costs money, matters more to a hobbyist than a tuning profile. KiCad 11 is expected about February 2027 and removes the bundled Python the plugin uses; a swap that edits a design needs back-annotation and the owner's review; the passive hint channel measured no gain (D109–D112, doc 17 §8), so the active interface must earn its keep before more is built on it
