# D95 — Unhelpful options kept as hidden flags

## Decision

Options that were measured and did not help are kept as hidden flags with their results recorded, not deleted: `--guide`, `--layer-assign`, `--order 3`, `--lns-open`, `--no-strict-first`, `--max-victims`, `--soft-growth`, `--history-weight`; `--package-pen` helps a little and is used only in portfolio extras

## Alternatives

Delete them (smaller surface)

## Reason

A flag costs a line in `main.cpp` and lets the next session repeat or extend the measurement; the results table in doc 16 §10 says what each did, so it is not re-tried blind (doc 16 §10)
