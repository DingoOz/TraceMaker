# D52 — `tracemaker-place` defaults to `--component-rules soft`

## Decision

`tracemaker-place` defaults to `--component-rules soft` (proximity pseudo-nets for crystals, load caps, ESD parts, regulator caps and generalised decoupling; objective-only, two-stage in full mode per D43); routing's default stays `off`

## Alternatives

Keep `off` (or `report`) until decap distances also improve

## Reason

Placed tiers B and C (70 boards, rules off vs soft side by side): clean pass 28 → 28 and 18 → 18, routed 5,163 → 5,156 and 9,538 → 9,539; XTAL-01 median 6.54 → 5.57 mm, load caps 3.11 → 2.81 mm, decaps 3.17 → 3.17 mm (losses traced to the router keeping a different candidate). Full mode, 23 boards × 3 seeds (D43): crystal and load caps better, decaps equal. No routing cost, a measured gain for crystals; doc 15 §14.3
