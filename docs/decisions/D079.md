# D79 — Plane targets exclude teardrops and unreachable fills

## Decision

Plane targets: a teardrop zone (`(attr (teardrop ...))`) is never a target; a fill is a target for a pad only if the pad can reach it (a via type the net may place, or a shared layer the net may use for tracks); with `--soft-zones` a routed item's contacts with same-net plane fills count in `joined`

## Alternatives

Leave teardrops to the 1 mm² rule; keep teardrops hard under soft zones; check reachability only for zone-only clusters; credit contacts in default mode too

## Reason

Orphaned teardrops are ≥ 1 mm² and became targets on signal nets; teardrops attached to pads were targets in every mode (complex_hierarchy defaults 77 → 84/84, 21 → 3 unconnected after refill). Unreachable planes replaced pad-to-pad connections with failed ones. Hard teardrops had no consistent effect. Default-mode credit would change outputs that are not broken; soft-zone output changes only where planes are. Quick tier byte-identical (doc 05 §32)
