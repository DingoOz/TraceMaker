# D35 — Escape feasibility reported beside the clean pass

## Decision

Escape feasibility (`tracemaker escape`) is reported beside the clean pass (`dead_pins`, `clean_pass_feasible`), never instead of it

## Alternatives

Drop infeasible boards from the benchmark

## Reason

PCBench ships no `.kicad_pro`; some boards cannot be routed clean by any router under the rules they are judged by (designers' own boards fail them). Hiding them would flatter both tools
