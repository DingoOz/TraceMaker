# D27 — `lib_id` detectors match the footprint name only

## Decision

`lib_id` detectors match the footprint name only, unless the pattern names a library (`connector_usb:`, `rf_module:`)

## Alternatives

Match the whole `library:footprint` string

## Reason

Library nicknames are free text: on PCBench UCCBPCB the nickname `usb_ccb_custom:` made an MCU, a jumper and headers "USB connectors" (precision first, doc 15 §9.1)
