# D128 — `--first-nets-ordered` routes first nets in list order

## Decision

`--first-nets-ordered`: route the `--first-nets` in the order of the list (doc 05 §49)

## Context

The group was only moved to the front; its inner order ignored the list, which made an order experiment on the EtherCAT shield meaningless

## Consequences and results

Off by default, nothing changes without it; a global ordering by list position would change existing crystal-line uses
