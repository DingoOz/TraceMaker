# D68 — Via in pad at the board minimum via, opt-in

## Decision

A via in pad (`--via-in-pad`) is the board's minimum via, only for inner balls or enclosed pads, at four vias at the current via price on either end, one per pad; none when the minimum via could not be read

## Alternatives

A fixed price; a fallback size

## Reason

Rule 6. The fixed price was undercut when the clean-up raises the via price, and the penalty was charged at the source only: on `inpad_cost` both balls took a via in pad instead of two ordinary vias (review of PR 1)
