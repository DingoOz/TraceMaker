# D84 — Board-prep and route guidance as agent skills

## Decision

Board preparation and routing guidance ship as two agent skills in `skills/` (`tracemaker-board-prep` with a stdlib `preflight.py`, `tracemaker-route` with a stdlib `signoff.py`), installable with `npx skills add`. Rule findings come from `tracemaker drc`'s diagnostics, the preflight's own vocabulary only when the binary is absent; the escape check uses the suggested route's zone and via options; sign-off judges both boards beside the input's project files. For connections the route leaves open the route skill goes through more search first, then the stuck report, and only then an advice file that the agent writes itself (D109's channel with the agent as the advisor), and says that the measured gain of hints is none (doc 17 §8); a test checks that every option the skills name exists in the engine's commands

## Alternatives

Document the advice only in docs/; reimplement the rule engine's vocabulary in the preflight; judge the routed file where it lies

## Reason

Speed and legality depend on project settings users do not see (an unused fine class, a cache-disabling rule, stale fills after deleting routing). The engine is the authority on which rules it applies. KiCad finds a board's project by file name: judged where it lies, a routed StickHub showed 449 false added errors (track_width, clearance, edge) against 1 with its project
