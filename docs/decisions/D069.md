# D69 — `--first-nets` routes named nets first and protects them

## Decision

`--first-nets` routes the named nets first, again after every restart, and neither negotiation nor the via clean-up rips them for other nets

## Alternatives

Length limits per net; a crystal corridor from the component rules

## Reason

The simplest control that fixed the case (crystal 25.7 → 4.3 / 5.1 mm); the catalogue (doc 15) detects crystals and could fill the list
