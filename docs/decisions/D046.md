# D46 — Evidence code D for rules with TraceMaker default values

## Decision

Catalogue evidence gains a fourth code, **D**: the cited source was read and supports the rule, but gives no number, so the value is a TraceMaker default. D rules are demoted from hard to soft at run time like R rules; each verified rule carries a `checked` field (date, status, document, section/page). The 41 R rules were checked against their sources (doc 15 §8.10): 9 confirmed, 9 corrected, 11 left as defaults (D), 12 not verifiable (stay R)

## Alternatives

Keep R for every rule with a TraceMaker default; mark the rules V once the qualitative statement is read

## Reason

R meant "not re-read", which is no longer true for 29 rules; V would claim the numbers come from the source when they do not. D keeps both facts visible and keeps those rules from becoming hard by accident. No current D rule is hard and no engine-read parameter changed (RF-03, SHLD-01 and BUCK-07 values changed; their kinds are not enforced yet), so placement and routing are unchanged
