# D13 — Courtyard gap fallbacks in full placement

## Decision

Full placement aims for a 0.25 mm courtyard gap (board rule if present), falling back to KiCad's default of 0, then to keeping unplaceable parts at their input positions, then to the refine result

## Alternatives

Always 0; always 0.25 mm

## Reason

Most human boards are packed below 0.25 mm; the fallbacks keep full mode usable on dense boards
