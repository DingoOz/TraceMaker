# D56 — Global router v2 kept off and M6 closed

## Decision

Global router v2 (net-shared edges, via capacity, layer-true corridors, integer costs) is kept off, and the GPU pattern/maze port is not built; M6 is closed

## Alternatives

Turn corridors or the map on; port GAMER/GGR kernels

## Reason

18 hard boards at a fixed budget: 13,305 routed without, 12,967 with corridors, 13,324 with the map (noise). Tile-graph routing takes 0.02–0.5 s per board (doc 05 §19)
