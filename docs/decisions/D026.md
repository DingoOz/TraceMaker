# D26 — Component-rule catalogue in YAML, embedded as generated JSON

## Decision

The component-rule catalogue stays `docs/component_rules.yaml`; `scripts/crules_catalogue.py` writes `src/crules/catalogue.json`, which the build embeds; a ctest fails if the JSON, the YAML and the rule ids in doc 15 drift

## Alternatives

A YAML parser in the engine; JSON as the edited source

## Reason

One small generated file instead of a new dependency; the YAML keeps comments and stays readable for people editing rules
