# D1 — Engine in C++20 and CUDA, viewer in TypeScript

## Decision

Engine in C++20 + CUDA; viewer in TypeScript + WebGL2/WebGPU; harness and plugin in Python

## Alternatives

Rust core (as KiCadRoutingTools); all-Python

## Reason

CUDA ecosystem, existing C++ design, GCC 15 + nvcc available; Python is what `kicad-cli`/IPC tooling uses
