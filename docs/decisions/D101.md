# D101 — Breakout portfolio with warm-started rounds

## Decision

Portfolio on a breakout board (`--variants` > 1): variant 0 is the plain breakout profile, the others draw order, via cost, crossing cost, direction strength, package penalty and temperature from fixed sets with a counter-based generator (`--breakout-portfolio 0` restores the designed eight); `--rounds R` splits the budget into R rounds, and after each every variant continues from the best result so far (warm start by connection)

## Alternatives

The designed eight (exact bends, longest first, 2× pitch variants); independent variants only

## Reason

Variants of the designed list are wrong for breakouts (fast bends and shortest first win; longest first routes 5 against 7 of 76); rounds point all search at the best state. See doc 16 §12 for the measurements
