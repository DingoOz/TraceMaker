# D185 — The plugin reads per-project settings and shows the run report

## Context

M23 E2 (doc 18 §20, D183). The KiCad actions were configured only through environment variables set before KiCad starts, and their
output went to stdout, which a KiCad user may never see. A refill after routing was a second undo step.

## Decision

- `kicad_plugin/tracemaker_settings.py`: both actions read `tracemaker.json` in the project folder (route options, power width, refill,
  report, reroute, placement, the nets action's work), strictly: an unknown key or a wrong value stops the action with a message naming
  it. The environment variables keep working and win over the file.
- The plugin's defaults are `--time 120`, **`power_width_mm` 0.5** (D184's `--power-width`, which stays off in the engine) and
  **`report: browser`**: the run report is written to `~/.cache/tracemaker/reports/` and opened in the web browser (`project` also keeps
  it next to the board; `off`).
- When the options include ones the Python module does not take, the action runs the binary instead of dropping them.
- The refill stays after the commit: two undo steps (measured below).

## Alternatives

- **Refill inside the open commit**: tried in KiCad 10.0.6. It is still its own undo step, and it fills before the new copper is pushed
  (`bench/records/m23-e2`). Sending our own filled polygons is not possible: kipy's zone fills have no setter.
- **Power width off in the plugin too**: the plugin's user is finishing a board, where power at signal width is a known defect. On the
  power-wide set the cost was −2 of 4,038 connections, and the setting turns it off.
- **A dialog**: an IPC action is a separate process with no KiCad UI to draw in. A settings file per project works the same on every
  platform, and it is kept with the project.

## Consequences

A KiCad user gets wide power and a report by default, and keeps settings with the project. The run report opens in a browser even when KiCad
shows no plugin output. Docs: `kicad_plugin/README.md`, doc 08, doc 18 §20. Records: `bench/records/m23-e2`.
