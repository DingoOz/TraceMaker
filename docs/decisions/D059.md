# D59 — Restart-based successive halving stays off

## Decision

Successive halving for the portfolio (`--halving`) is restart-based and stays off

## Alternatives

Resumable router runs; halving on by default with fewer threads than variants

## Reason

24 boards: 12,385 / 12,451 routed at 2 / 4 threads against 12,402 / 12,508 for the first variants on the whole budget (doc 05 §22)
