# D4 — Octilinear lattice routing first, gridless later

## Decision

Detailed routing first on a fine octilinear lattice with exact validation; gridless tile plane later

## Alternatives

Gridless first (clean-sheet doc); Manhattan lattice (OrthoRoute)

## Reason

Faster to make correct, GPU-friendly; Manhattan-only routing scores poorly on mixed boards
