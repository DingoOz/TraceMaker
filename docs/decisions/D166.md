# D166 — Halving gives way to rounds and warm starts

## Context

Issue #63: with more `--variants` than `--threads`, `--halving` returned from `route_portfolio` before the rounds were set up, so
`--relax --round-work N --rounds M` gave a board byte for byte the same as without `--relax`, and nothing said so. The same held for
`--rounds`, `--round-work`, `--ramp-from`, `--island-slack` and `--state-in`. It also held for the relax rescue (D160, D163), which
is on by default and copies the job's options: with `--halving` each rescue pass was a second plain halving run, not relax, and
the warm pass's start routes were dropped. Halving (doc 05 §22, D59) restarts every rung from nothing, so it cannot run options
that continue from earlier routes.

## Decision

When any of those options is in force, the portfolio does not halve. All the chosen variants run the rounds on `threads`
workers, as without `--halving`. A line on stderr (and on the live page's log) says `--halving does not apply with relax`,
`rounds` or `a warm start`. `--halving` on its own is unchanged. The portfolio's own four rounds on breakout boards are a default,
not an option asked for, and halving still replaces them as before. The `--halving` help says so.

## Alternatives

- **Stop with an error when both are given.** The rescue sets relax by itself, so `--halving` would fail on every board the plain
  run leaves open.
- **Relax inside each rung.** Rungs restart from nothing, so they would throw away exactly what the rounds carry over, and it
  would need its own measurement. Halving is off by default and loses to the first variants on the whole budget (D59), so it does not
  justify that work.
- **Only print a warning and keep halving.** The user asked for relax, and the rescue relies on it. Relax is the measured gain
  (D160), and halving is not.

## Consequences

- `--halving` runs with a round option, and rescue passes after a `--halving` run, now route differently (and more). A run
  that uses `--halving` alone gives the same board as before.
- `tests/test_txn.cpp` checks that halving plus relax gives the same copper as relax alone.
- Docs: doc 05 §22 and the `--halving` help (CLI reference regenerated).
