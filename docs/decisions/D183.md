# D183 — Group E: features for a finished, usable KiCad board

## Context

By 2026-11-13 the roadmap's workable items were done; M17 macOS, M19 and M20 D3 wait on things outside the repository. The owner asked
for research into new features that help a KiCad user get a fully routed and useful board, and for work to start on them without waiting
for approval. Research: doc 18 §20 (this repository's records plus user threads and tool pages).

## Decision

Build group E in this order: E1 power nets routed wide from the start, E2 the plugin as a KiCad tool (per-project settings, one undo
with refill, report shown), E3 an off-angle cleanup, E4 a return-path and plane-gap check in the run report, E5 throughput. Each gets
its own decision record when built and is kept only if it meets its gate in doc 18 §20.2. The roadmap gets milestone M23 for group E.

## Alternatives

- **More completion work first** (M22 continued): the records put every repair within a few connections of the base, and 735 of 740 open
  pins are congestion. That is E5, last because it is the largest.
- **IR drop, fab and assembly export**: later or elsewhere. IR drop needs E1's widths and E4's plane model first; KiCad plugins already
  export BOM and CPL.

## Consequences

The roadmap gains M23. Nothing changes in the code with this record.
