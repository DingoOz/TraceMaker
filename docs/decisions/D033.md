# D33 — Escape planning in two of eight portfolio variants

## Decision

Escape planning runs in two of the eight portfolio variants (not all)

## Alternatives

All variants; opt-in only

## Reason

All variants: tier B +8 connections, tier C −7, BGA set +31, tier A equal: neutral on average, so it is an arm the portfolio can pick where it helps
