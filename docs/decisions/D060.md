# D60 — Plugin refills zones only on request or after moves

## Decision

The plugin refills zones only on request or after it moved footprints

## Alternatives

Always refill

## Reason

KiCad records the refill as its own undo step; the plugin's promise is one undo for a routing run (doc 08 §8)
