# D123 — One project brand, the trace logo

## Decision

The project has one **brand** (`branding/`): the trace logo (a red-layer trace, a via and a blue-layer trace between two pads, picked by the owner from 25 options) in a light and a dark form with outlined text, a square icon, PNGs, an `.ico` and a social preview. It is used in the README (`<picture>`, dark mode aware), the live viewer (favicon and header), the development site, and the KiCad package (`resources/icon.png` and the action's toolbar icons)

## Alternatives

Keeping the generated 64x64 board icon of the PCM script; text left as live fonts (the SVG changes with the reader's fonts); a logo with a drawn pen, chip or board (the owner chose the plain trace)

## Reason

The viewer already says red is front copper and blue is back copper, so the logo reads as the product; hollow pads and via keep it usable on any background; the PCM script reads the PNG from `branding/` and no longer draws its own
