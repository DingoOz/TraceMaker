# D65 — Rule areas block tracks and vias by own flags

## Decision

A rule area blocks tracks when it forbids tracks and vias when it forbids vias (the obstacle model read only areas forbidding tracks, and they blocked vias too)

## Alternatives

Keep the old reading

## Reason

KiCad's meaning; a full-board "no tracks" area on a plane layer is the usual way to keep a plane whole, and it made every via through that layer illegal. A "no vias" area blocked nothing before
