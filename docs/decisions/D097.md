# D97 — M14 plan as measured outcomes, not a build order

## Decision

The M14 plan (doc 16) is a plan with measured outcomes, not a design to build in order: hypotheses H1–H5 were tested first, and the build list is what survived. The deciding experiment (E1, tscircuit's own routes as guides) used its router as a measuring instrument only (bun, installed in the scratch area, no tscircuit code enters the engine)

## Alternatives

Build the planner first (as the plan listed)

## Reason

The experiments showed the topology planner (F1) is not justified by topology alone, and that search effort and negotiation limits were the cheap lever (doc 16 §4, §10)
