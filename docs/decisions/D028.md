# D28 — Component proximity rules reuse affinity pseudo-nets

## Decision

Component proximity rules reuse D25's objective-only two-pin pseudo-nets (`ExtractOptions::affinities`): weight 10, ×2 for a protection part to its connector; each part is pulled by one rule (crystal > oscillator > ESD > regulator > decoupling), D25's own ties are kept unchanged and win

## Alternatives

Hard distance constraints in the legaliser; a separate cost term

## Reason

Same exact incremental cost in every placer stage; reported HPWL/crossings/congestion unchanged; no conflicting pulls on one part; `off` reproduces the previous placer byte for byte
