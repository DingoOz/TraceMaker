# D53 — Global congestion map off, global router v2 deferred

!!! warning "Superseded by [D56](D056.md)"

## Decision

The global congestion map (`--global-congestion`, doc 05 §16) stays off, and the rest of global router v2 (Steiner topology, via capacity, GPU pattern/maze port) is deferred

## Alternatives

Turn the map on; continue with v2

## Reason

18 hard boards at a fixed budget: 13,285 routed without, 13,289–13,294 with (noise); corridors 12,933. With cut-based capacities under 5 % of tiles reach 6/8 utilisation; about two thirds of unrouted connections on tiers B–D are boxed-in pins, which tiles cannot see
