# D24 — `--route-check` restores a rejected placement by copying the input

## Decision

`--route-check` restores a rejected placement by copying the input file

## Alternatives

Re-saving the edited document

## Reason

The editor edits the document in place, so re-saving wrote the *new* placement while reporting "kept input" (M7 bug, fixed 2026-10-03)
