# D14 — SimPL spreading instead of electrostatic density

## Decision

Global spreading uses SimPL rather than the electrostatic method

## Alternatives

ePlace/DREAMPlace-style density

## Reason

Simpler on CPU and adequate for PCB part counts (doc 04 §7)
