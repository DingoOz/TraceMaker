# D19 — PCM package without a bundled engine by default

!!! warning "Superseded by [D121](D121.md)"

## Decision

PCM package uses metadata schema v2 with `runtime: ipc`, does not bundle the engine by default (env `TRACEMAKER` / `TRACEMAKER_PYTHONPATH`), optional Linux bundling; licence field defaults to GPL-3.0-or-later until the project licence is chosen (requirement N8)

## Alternatives

Always bundle binaries

## Reason

Native builds depend on the system's CUDA runtime, SQLite and libstdc++ and the module on the Python version; KiCad 10 ships PCM schema v2 and kicad-python 0.8 validates against it
