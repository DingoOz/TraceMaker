# D10 — Browser viewer served by the engine

## Decision

Viewer in the browser, served by the engine; WebGL2 baseline, WebGPU when available

## Alternatives

Native ImGui/Qt; WebGPU-only

## Reason

Remote use from any machine, GPU rendering, no install; WebGPU is not yet default on Linux Firefox
