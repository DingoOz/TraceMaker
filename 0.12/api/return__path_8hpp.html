Detailed Description

Reference-return audit of high-speed nets (issue #7, docs/05-routing.md §42, D114).

KiCad's DRC cannot tell whether a fast trace has continuous copper under it. A dogbone escape punches antipads through the reference pour, a plane can be split, a layer change can come without a nearby stitch: the signal is DRC-clean and its return current still walks around the void, which grows the loop area and the inductance. This pass answers a geometric question per net: does the trace have copper under it on the adjacent reference layer, and where it does not, how far does the return detour?

It is read-only (it adds nothing to the board) and it is a geometric model, not a field solver: the return of a signal over copper is taken to be its mirror image on the reference layer, across a void it is the shortest path that stays on the remaining reference copper (Dijkstra over the visibility graph of the reference polygon's vertices; Lee and Preparata 1984), and at a layer change it closes through the nearest stitching via of the reference net, or the nearest capacitor between the two reference nets, within a radius. The return does not close through "one assumed GND ball": at a footprint the nearest pad of the reference net is the assumed return pad (the comment on the issue).
