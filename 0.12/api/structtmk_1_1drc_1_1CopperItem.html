◆ span

model::LayerMask tmk::drc::CopperItem::span = 0

Vias and pads whose copper KiCad removes on layers nothing connects to (model::UnconnectedLayers, doc 05 §60).

On those layers only the hole is left, and KiCad's clearance test takes the hole for the item's copper there. Such an item is split: the item with the copper (layers without the bare layers) and a second item of the same kind and index whose layers are the bare ones and whose shape is the hole. bare_part on the first points to the second, bare_of on the second to the first. The second is no node of the connectivity graph and is not reported on its own. span is the padstack's whole layer set (KiCad's GetLayerSet), which rule conditions see; 0 for items that are not split.
