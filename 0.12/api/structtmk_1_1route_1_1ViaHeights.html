Detailed Description

The length a via adds to its net in KiCad's length calculation (KiCad 10, BOARD_STACKUP::GetLayerDistance): the stackup between the two copper layers the via joins, with the copper of an outer layer in full and of an inner layer by half.

What a via adds to a net's length (drc/length.hpp, where KiCad's length check lives).

A board without a stackup block gets KiCad's default one (35 um copper, 10 um per solder mask, the rest of the board thickness shared evenly between the dielectrics). Empty (every via 0) when the project turns "use height for length calculations" off.
