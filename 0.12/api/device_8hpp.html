Detailed Description

GPU discovery and memory admission control (design doc 07 §4).

The GPUs on the development machine are shared with other jobs, so free memory is scarce and changes over time. Callers ask has_free_memory before large allocations and fall back to the CPU reference path when it fails; results are identical either way.
