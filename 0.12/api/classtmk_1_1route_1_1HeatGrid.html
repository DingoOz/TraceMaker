std::vector< std::uint8_t > tmk::route::HeatGrid::bytes ( ) const

One byte per cell, row-major: round(255 * sqrt(v / max)), at least 1 for any non-zero cell so faint activity stays visible.

The square root keeps heavy-tailed counts (a few hot spots) from washing out everything else.
