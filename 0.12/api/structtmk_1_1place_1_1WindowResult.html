Detailed Description

Exact window (doc 04 §3 F, without CP-SAT): the best placement of parts (others fixed) over a candidate set per part (its own spot, the other window parts' spots, its HPWL-optimal spot; four rotations each), by branch and bound with an HPWL bound.

prune = false enumerates every combination (reference path). pl is updated only when the optimum is strictly better than the start.
