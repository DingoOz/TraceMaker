3// (E) Detailed placement by simulated annealing (design doc 04 §3 E; Kirkpatrick, Gelatt, Vecchi, Science
4// 1983; move set after TimberWolf, Sechen & Sangiovanni-Vincentelli, IEEE JSSC 1985).
5//
6// Moves: shift (radius shrinks with temperature), pull towards the weighted median of the connected pins,
7// rotate by 90/180/270°, swap two interchangeable parts (same footprint, side and orientation class). Every
8// move is checked exactly before it is applied, so the state is always legal. Cost (integer, incremental):
9// weighted HPWL + α · (crossings between minimum-spanning-tree airwires of different signal nets), the
10// crossings counted against a uniform segment grid. Independent runs with different seeds go in parallel and
11// the best is kept (ties: lowest run index); run budgets are counted in moves, so results do not depend on
12// thread timing unless the wall-time limit stops a run.
13//
14// M8 additions (doc 04 §3 E, G):
15// - Parallel tempering (replica exchange; Swendsen & Wang, PRL 57, 1986; Hukushima & Nemoto, J. Phys. Soc. Jpn.
16// 65, 1996): `runs` replicas at geometric temperatures run fixed-length sweeps in parallel; between sweeps,
17// neighbouring temperatures exchange replicas with the Metropolis criterion, decided sequentially from a
18// dedicated random stream, so the result does not depend on the thread count.
19// - Large-neighbourhood search (Shaw, "Using constraint programming and local search methods to solve vehicle
20// routing problems", CP 1998): rip up a window of nearby parts and re-place them, exactly (branch and bound
21// over candidate slots and rotations) for small windows, greedily otherwise; kept only if the cost falls.
22// - A routability term β · RUDY overflow (place/congestion.hpp).
23//
24// Side assignment (doc 04 §3 C/E, D48; opt-in): a flip move puts a part on the other side (KiCad's mirrored
25// footprint, problem.hpp kStates) at its body centre or at the weighted median of its nets, and the cost gains
26// a via estimate for nets with surface-mount pins on both sides.

39struct AnnealOptions {
40 std::uint64_t seed = 1;
41 int runs = 8;
42 int threads = 8;
43 double effort = 1.0; // moves per run = effort × 4000 × movable parts (at least 20 000)
44 double alpha_cross_mm = 2.0; // one airwire crossing costs as much as this much signal HPWL
45 double time_limit_s = 0; // wall-time stop (0 = none); hitting it makes the result timing-dependent
46 bool refine = false; // start cool and with small moves (the start is already a good placement)
47 // Routability: cost of 1 mm of RUDY overflow in mm of signal HPWL (0 = off; resolution 0.1). `congestion`
48 // is the capacity map (built with default options when null).
49 double beta_congestion = 0;
50 const CongestionMap* congestion = nullptr;
51 bool tempering = false; // parallel tempering over `runs` replicas instead of independent runs
52 int exchange_interval = 0; // moves per replica between exchange attempts (0 = auto)
53 double lns_rate = 0; // probability that a step is an LNS window instead of an ordinary move
54 int lns_window = 6; // parts per LNS window (≤ 12)
55 int exact_window = 4; // windows up to this size are repaired exactly (branch and bound)
56 std::vector<int> focus; // parts LNS windows are centred on (empty: any movable part)
57 std::uint64_t trace_every = 0; // record the live state every this many steps (0 = off; video recording)
58 // Side assignment (doc 04 §3 C/E, D48): flip moves for parts with Part::may_flip(), and the via estimate
59 // via_mm · Σ w · min(front, back surface-mount pins) per net in the cost (wirelength.hpp side_vias).
60 bool flip = false;
61 double via_mm = 2.0; // one estimated via costs as much as this much signal HPWL
62 double flip_rate = 0.1; // share of ordinary moves that are flips (only drawn when flipping is on)
63};
