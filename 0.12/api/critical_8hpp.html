Detailed Description

Critical nets, from what the board's parts are (issue #24, docs/05-routing.md §44, D117).

JLCPCB's first rule of routing is to route the critical signals first. Which signals are critical is not in the netlist, but the component rules (doc 15) know the roles the nets play: the data lines of a USB port, the pairs of an Ethernet PHY, a crystal's two pins, the clock of a memory interface. This turns the roles into tiers: 1 clocks, crystals and RF lines (the signals that radiate and that nothing may disturb), 2 high-speed differential links, 3 memory and other fast parallel buses. A tier is the order of routing; the user's own list (--critical-nets) is tier 1.
