Detailed Description

Internal: the incremental annealing state shared by simulated annealing, parallel tempering, large- neighbourhood search and exact windows (anneal.cpp, tempering.cpp, lns.cpp).

Not part of the public API.

The state is always legal for the movable parts (every committed move passed the exact test). Its cost is an exact integer, kept incrementally: Σ w·HPWL + α·crossings + β·RUDY overflow.
